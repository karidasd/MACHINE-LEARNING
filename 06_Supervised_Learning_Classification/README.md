# 🏷️ Μάθημα 6: Supervised Learning - Classification

Συνεχίζουμε με το δεύτερο μεγάλο κομμάτι της Μάθησης με Επίβλεψη: την **Κατηγοριοποίηση (Classification)**. Αντί να μαντεύουμε αριθμούς, τώρα μαντεύουμε... κατηγορίες!

### ❓ Ερωτήματα που θα απαντήσουμε:
* Πώς ένα μοντέλο αποφασίζει αν ένα email είναι Spam ή όχι;
* Τι διαφορά έχει το Classification από το Regression;
* Πώς συγκρίνουμε δύο διαφορετικά μοντέλα μεταξύ τους;

### 🛠️ Νέα Εργαλεία:
* **Logistic Regression**: (Παρά το όνομά της, είναι για κατηγοριοποίηση!)
* **Decision Trees (Δέντρα Απόφασης)**: Ένα μοντέλο που σκέφτεται όπως ο άνθρωπος, κάνοντας ερωτήσεις "Ναι/Όχι".
* **Iris Dataset**: Το πιο διάσημο dataset στην ιστορία του Machine Learning.
