# 📈 Μάθημα 5: Supervised Learning - Regression

Καλώς ήρθατε στον μαγικό κόσμο της Μηχανικής Μάθησης! Ξεκινάμε με το **Supervised Learning (Μάθηση με Επίβλεψη)** και συγκεκριμένα την **Παλινδρόμηση (Regression)**.

### ❓ Ερωτήματα που θα απαντήσουμε:
* Τι είναι το Supervised Learning;
* Πώς μπορούμε να προβλέψουμε μια *συνεχή* τιμή, όπως η τιμή ενός σπιτιού ή ο μισθός ενός εργαζομένου;
* Πώς 'εκπαιδεύουμε' ένα μοντέλο να μαθαίνει από το παρελθόν;

### 🛠️ Νέα Εργαλεία:
* **Scikit-Learn (`sklearn`)**: Η πιο ισχυρή βιβλιοθήκη για Machine Learning στην Python.
* **Linear Regression**: Το πιο κλασικό και θεμελιώδες μοντέλο πρόβλεψης.
* **Train/Test Split**: Πώς χωρίζουμε τα δεδομένα μας για να ελέγξουμε αν το μοντέλο έμαθε πραγματικά ή απλά "αποστήθισε".
