# 🧩 Μάθημα 7: Unsupervised Learning - Clustering

Τι γίνεται όταν έχουμε δεδομένα αλλά δεν ξέρουμε τι ψάχνουμε; Καλώς ήρθατε στο **Unsupervised Learning (Μάθηση χωρίς Επίβλεψη)**. Εδώ αφήνουμε τον αλγόριθμο να βρει μόνος του τα κρυφά μοτίβα!

### ❓ Ερωτήματα που θα απαντήσουμε:
* Πώς ανακαλύπτουμε ομάδες (clusters) σε δεδομένα χωρίς ετικέτες;
* Τι είναι το Customer Segmentation και πώς εφαρμόζεται στο Marketing;
* Πώς δουλεύει ο αλγόριθμος K-Means στο παρασκήνιο;

### 🛠️ Νέα Εργαλεία:
* **K-Means Clustering**: Ο πιο διάσημος αλγόριθμος ομαδοποίησης.
* **Make Blobs**: Ένα εργαλείο του sklearn για να φτιάχνουμε συνθετικά δεδομένα (ψεύτικα δεδομένα για εξάσκηση).
* **Προχωρημένα Scatter Plots**: Οπτικοποίηση των ομάδων με διαφορετικά χρώματα.
