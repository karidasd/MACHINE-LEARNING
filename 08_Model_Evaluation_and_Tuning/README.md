# ⚖️ Μάθημα 8: Αξιολόγηση Μοντέλων (Evaluation & Tuning)

Ένα μοντέλο εκπαιδεύτηκε. Είναι όμως καλό; Στο Data Science, η εμπιστοσύνη είναι καλή, αλλά η μέτρηση είναι καλύτερη. 

### ❓ Ερωτήματα που θα απαντήσουμε:
* Γιατί το 90% Accuracy (Ακρίβεια) μπορεί μερικές φορές να είναι... καταστροφικό;
* Πώς καταλαβαίνουμε τα λάθη του μοντέλου μας;
* Πώς ισορροπούμε ανάμεσα στο να βρούμε όλα τα θετικά αποτελέσματα (Recall) και στο να είμαστε σίγουροι για αυτά (Precision);

### 🛠️ Νέα Εργαλεία:
* **Confusion Matrix (Πίνακας Σύγχυσης)**: Ο χάρτης των λαθών του μοντέλου.
* **Classification Report**: Αναλυτική αναφορά με Precision, Recall και F1-Score.
* **Random Forest**: Ένα πανίσχυρο μοντέλο που αποτελείται από... ένα δάσος από Decision Trees!
