## 📂 Δομή του Αποθετηρίου (Curriculum)

Αυτό το αποθετήριο δεν είναι απλά μια συλλογή αρχείων, αλλά ένα **ολοκληρωμένο ταξίδι** στον κόσμο του Machine Learning:

1. **[01_Introduction](01_Introduction)**: Βασικές έννοιες και εργαλεία.
2. **[02_Datasets](02_Datasets)**: Πού βρίσκουμε δεδομένα και πώς τα διαβάζουμε.

4. **[04_Visualization_Mastery](04_Visualization_Mastery)**: Οπτικοποίηση δεδομένων (Matplotlib, Seaborn).

### Η Καρδιά του Machine Learning
5. **[05_Supervised_Learning_Regression](05_Supervised_Learning_Regression)**: Πρόβλεψη συνεχών τιμών (π.χ. Γραμμική Παλινδρόμηση).

9. **[09_Real_Time_Inference_and_Deploy](09_Real_Time_Inference_and_Deploy)**: Πώς 'σώζουμε' το μοντέλο μας (joblib) για να το χρησιμοποιήσουμε σε πραγματικές web εφαρμογές!
